# Оно тебе надо

Первая проектная работа Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/as1ndyx/ono-tebe-nado-ad

## О проекте

Страница содержит шапку с навигацией и контактами, обложку, три карточки лотов, описание аукциона и подвал с социальными ссылками.

Использованы семантический HTML, CSS Grid и Flexbox, локальные шрифты Raleway и изображения из заготовки. Повторяющиеся адреса и затемняющие оверлеи используют общие классы.

[Макет в Figma](https://www.figma.com/design/PqHJvUBvwCsv8UmOUPWBXJ/?node-id=0-3).

## Просмотр

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются, пути к изображениям, стилям и шрифтам относительные.

Вёрстка рассчитана на ширину 1100 px согласно заданию. Мобильная адаптация и логика аукциона не входят в этот этап: кнопка ставки и ссылки карточек являются элементами учебного макета.

## Проверки

Исходный процесс `Tests` в `.github/workflows/tests.yml` запускает проверки Яндекс Практикума при отправке коммитов на GitHub. Для их выполнения репозиторий должен быть публичным.
